# 作战策略编辑器设计

日期：2026-10-19。状态：用户已确认交互并授权实现。

## 目标与范围

客户端侧边栏新增“作战策略”，交付可编辑、校验、保存、重新加载的 JSON。先做编辑器与数据契约，后续由 MAP Python Agent 消费。本轮不开发识别、战斗执行、任务策略选择。沿用 Avalonia、SukiUI 主题，无新增运行依赖。中文文案、注释与文档；保留工作区已有标题栏改动，在当前功能分支实施，不自动提交或推送。

## 页面

- 左侧策略列表，支持新建、复制、重命名。内置默认策略只读、可复制。
- 右侧没有顶部工具栏；阶段卡片纵向堆叠、可命名、拖动展示顺序、多张独立展开与折叠，不生成摘要。
- 标题栏左键展开折叠，手柄拖动；右键菜单包括重命名、复制、删除、设为初始阶段。
- 最后阶段下方用加号新增；底部固定保存、删除当前策略、全部展开、全部折叠。
- 阶段数量自定，至少一个；单阶段可运行全场。初始阶段单独指定，展示顺序不决定执行顺序。
- 阶段内配置行动、乱舞、可排序的跳转规则；跳转目标可为任意阶段，允许循环。
- 未保存时切换策略或离页弹窗：保存并继续、放弃修改并继续、取消。保存失败留在原页并保留内容。

## 行动

- 奥义与炸弹可交换优先级，连线最后；普通与乱舞共用顺序。
- 炸弹仅勾选允许的一二三级，不设各等级条件；执行端在允许且可用等级中优先三级、二级、一级，四级为自动爆炸过渡。
- 奥义按三个位置勾选、拖动排序、设置各自前置。自身就绪内置，不开放为条件。优先级不满足则跳过，每次成功后重新识别再从头检查。
- 示例：顺序 2、1、3；2 要求 3 就绪，1 无额外条件，3 要求本阶段 2 已释放。3 未就绪时可先放 1。
- 普通连线可选四色优先级；存在七连候选时在达到七连的颜色中排序，否则在全部颜色中排序。同色路径交给执行算法。
- 乱舞分别开关使用奥义、使用炸弹，开启仍受本阶段条件与勾选限制；留色开关最多选择一种颜色。

## 条件与计数

- 可嵌套的全部或任一条件组；叶子用下拉、数字输入编辑，布尔期望值和比较表达否定。首版没有脚本、文本表达式和整组取反。
- 支持本场或阶段普通连线手数、敌我血量数值与百分比、其他位置奥义就绪、位置奥义已释放、当前是否乱舞。
- 多位置状态可选全部或任一。进入阶段重置阶段手数和阶段已释放记录，本场手数保留；只统计成功普通连线。
- 转变先于行动检查，多条命中选排序首条。执行端每次一步后确认，防止无新观察和无行动的跳转循环。
- 未识别为未知，取反也不是成立。百分比最大血量来源待执行端实机核对。

## 文件契约与实现选择

- 使用统一配置目录下 strategies 文件夹，每策略一个 GUID N 格式文件名加 .json，名称在文件内；阶段和转变同样有稳定标识。
- UTF-8、缩进、snake_case、schema_version 为 1。顶层为 schema_version、id、name、initial_stage_id、stages。
- 阶段为 id、name、actions、frenzy、transitions；行动包含两类优先级、允许炸弹等级、按优先级排列的位置规则与普通连线颜色。乱舞包含开关与保留色。
- 条件用 type 为 group 或 predicate 区分；组有 match 为 all 或 any 和 children；叶子有 metric、比较或期望值、阈值、位置范围。禁用任意 CLR 类型解析。
- 默认策略一个阶段，奥义优先，三级炸弹，三个位置按 1、2、3 全启用、无额外前置，连线无颜色偏好，乱舞允许奥义炸弹且不留色，无跳转。新建采用可编辑默认配置。
- 复制策略生成独立策略、阶段与规则标识并重映射内部目标；复制单阶段生成新标识，其他目标不变，自身目标映射副本。
- 校验至少一个阶段、有效初始阶段与跳转目标、位置等级不重复、合法数值、百分比 0 到 100、手数为非负整数。空转变条件、空嵌套组不可保存，奥义无额外条件合法。条件保护上限 16 层。
- 保存先校验序列化，同目录临时文件替换。失败不吞异常、不清除修改标记、不破坏旧文件。
- 损坏文件和未来版本明确报错，不悄悄覆盖。内置默认不可覆盖删除。删除策略可确认后执行，不检查任务引用；任务找不到策略时默认回退是后续执行端契约。
- 删除被其他阶段引用的阶段时提示来源并阻止，先修改跳转。唯一阶段不能删，初始阶段须先改指定。
- 运行态血量、手数、释放记录不落盘；编辑折叠状态不进入战斗契约。
- 条件在阶段内就地展开，局部编辑不重建整页。保存、放弃、取消与窗口关闭、离页都接入保护。

## 验收

侧边栏与策略管理可用；阶段卡片与嵌套条件完整编辑；顺序、跳转和开关保存后重载一致；默认只读、复制独立、引用删除校验、坏文件及保存失败有测试。全量单元测试、桌面构建、差异格式检查通过，未进行的实机交互明确记录。
