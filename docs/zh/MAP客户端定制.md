# MAP 客户端定制记录

本仓库用于 MaaPazugiri（MAP）的专属客户端，从 MaaXYZ/MFAAvalonia 建立 fork。定制保留 MFAA 的经典布局、控件与主题，业务资源和战斗策略执行由 MAP 项目维护。

## 上游基线

- 上游仓库：<https://github.com/MaaXYZ/MFAAvalonia>。
- 当前基线：`450a8f3134d2b5ac3fce4fc8eeb3e745197b1717`，上游版本为 `v2.16.3-beta.1`。
- 定制仓库：<https://github.com/NotZoruak/MFAAvalonia>。

## 作战策略编辑器（2026-10-19）

- 侧边栏新增“作战策略”。左侧管理策略，右侧纵向排列可命名、拖动和折叠的阶段卡片，末尾加号新增，底部固定保存、删除、全部展开与折叠。
- 阶段标题右键可重命名、复制、删除和设为初始阶段；转变允许任意目标，以嵌套的全部或任一条件组表达。
- 支持炸弹等级、奥义位置排序与前置、连线颜色优先级、乱舞开关与留色，手数、血量数值与百分比及奥义状态条件。
- JSON 保存到统一配置目录的 `strategies/`，默认策略只读可复制；切换策略、离页和关闭窗口有保存、放弃、取消弹窗，保存失败保留原文件与草稿。
- 实现位于 `Features/CombatStrategies/`、`Views/Pages/CombatStrategyView` 与对应模型，接入 `App`、`Instances`、`RootViewContent` 和窗口关闭处理。
- 本轮只交付编辑器与文件契约，任务选择和战斗执行后续接入。详见[作战策略 JSON 格式](作战策略JSON格式.md)。
- 控件编辑及文件重载已纳入测试；真实窗口鼠标拖动、弹窗和不同尺寸仍需交互验收。
- 2026-10-19 全量测试 58 项通过（35 项策略测试、23 项既有本地测试），桌面构建 0 错误、6 项既有依赖告警。独立复核后修复了缺少必备配置时静默补值的问题，拖动排序也覆盖了原位、上下移动和末尾插入。

## 首页布局（2026-10-17）

- 左列：任务列表，占满可用高度。
- 中列：上方任务设置，下方任务说明。
- 右列：日志，占满可用高度。
- 沿用上游的等宽三列和中间卡片高度比例，保留原有卡片拖拽、缩放和布局保存能力。
- 移除首页实时视图卡片及其专用动画、可见性同步代码。首页不会因为开启实时视图开关而恢复该卡片。
- 总控台继续使用共享的实时图像，设置页的实时视图开关和刷新率保留；截图、连接和图像刷新逻辑继续沿用上游实现。

## 总控台实时画面（2026-10-17）

- 实时画面卡片默认尺寸由横向的 360×240 调整为竖向的 240×420，以适配竖屏游戏画面。
- 保留总控台现有缩放、全屏查看和卡片操作。

### 布局配置与升级核对

`mfa_layout.json` 和用户保存的布局继续按上游规则加载。本次修改客户端默认布局，并在 MAP 业务仓库增加 `resource/base/mfa_layout.json`，配套提供日志覆盖右侧整列的四卡片布局。资源布局首次加载或内容哈希变化时，会按上游规则应用到配置；之后继续保存用户的拖拽和缩放结果。更新上游时同时核对首页卡片、总控台共享图像、实时视图设置及布局加载规则。

### 构建核对

```powershell
dotnet build MFAAvalonia.Desktop/MFAAvalonia.Desktop.csproj -c Debug -r win-x64 --no-restore --nologo
```

2026-10-17 执行上述命令，构建退出码为 0，0 个错误、23 个上游既有警告（包含依赖安全告警）。客户端差异通过 `git diff --check`。

完整交互仍需在实际客户端中核对，包括任务切换、卡片拖拽和缩放、总控台实时图像，以及设置开关启闭后首页与总控台的表现。
